Package 3: Socket.IO Security.

Contexte: donjon-dragon, NestJS 10, Socket.IO. Auth deja en place (JWT, guards). Architecture hexagonale.

A FAIRE:

1. Cree shared/src/chat-schema.ts:
   import { z } from 'zod';
   export const JoinRoomDto = z.object({ roomId: z.string().min(1) });
   export type JoinRoomDto = z.infer<typeof JoinRoomDto>;
   export const SendMessageDto = z.object({ roomId: z.string().min(1), content: z.string().min(1).max(2000) });
   export type SendMessageDto = z.infer<typeof SendMessageDto>;
   export const ChatMessage = z.object({ id: z.string(), senderId: z.string(), senderName: z.string(), roomId: z.string(), content: z.string(), timestamp: z.date() });
   export type ChatMessage = z.infer<typeof ChatMessage>;
   Ajoute export dans shared/src/index.ts.

2. Cree back/src/chat/domain/chat-message.entity.ts:
   - createMessage(senderId, senderName, roomId, content): ChatMessage (genere id + timestamp)

3. Cree back/src/chat/interface/chat.gateway.ts:
   - @WebSocketGateway({ namespace: /game, cors: { origin: process.env.FRONTEND_URL || 'http://localhost:5173', credentials: true } })
   - handleConnection(client): verifie JWT dans client.handshake.auth.token
     - Si pas de token ou invalide → client.disconnect()
     - Si valide → client.data.user = decoded payload, log connection
   - handleDisconnect(client): log deconnexion, nettoyage rooms
   - @SubscribeMessage('join:room'): valide JoinRoomDto, client.join(roomId)
   - @SubscribeMessage('leave:room'): client.leave(roomId)
   - @SubscribeMessage('message:send'): valide SendMessageDto, cree message, broadcast dans la room
   - Rate limiting: Map<clientId, { count, resetAt }>, max 10 messages/30s
   - Si rate limit depasse → emit 'error' au client, ne broadcast pas

4. Cree back/src/chat/interface/chat.module.ts:
   - Importe le gateway
   - Fournit ChatGateway

Execute: pnpm typecheck && cd back && pnpm test.
