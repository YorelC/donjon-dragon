Package 6: Frontend Security.

Contexte: donjon-dragon, React 18 + Vite + Zustand + TanStack Query + React Router + Socket.IO client.

A FAIRE:

1. Cree front/src/features/auth/auth.service.ts:
   - API calls: POST /auth/login, /auth/register, /auth/refresh, GET /auth/me
   - Utilise fetch, pas axios (pas de dep supplementaire)
   - baseURL: import.meta.env.VITE_API_URL || 'http://localhost:3000'
   - Stocke tokens dans localStorage (accessToken, refreshToken)
   - Intercepte 401 → try refresh → retry, si fail → clear tokens

2. Cree front/src/features/auth/auth.store.ts:
   - Zustand store: { user, accessToken, isAuthenticated, isLoading, error }
   - Actions: login, register, logout, refreshToken, loadUser

3. Cree front/src/features/auth/guards/protected-route.tsx:
   - Wrapper React Router: verifie auth.store.isAuthenticated
   - Si pas auth → Navigate to /login
   - Si auth → render children

4. Cree front/src/features/auth/guards/guest-route.tsx:
   - Wrapper React Router: si auth → Navigate to /dashboard

5. Cree front/src/features/auth/components/login.view.tsx:
   - Formulaire email + password
   - react-hook-form + Zod (LoginDto du shared)
   - Affiche erreur si login fail

6. Cree front/src/features/auth/components/login.container.tsx:
   - Appelle auth.store.login
   - Passe les props a login.view

7. Cree front/src/features/auth/components/register.view.tsx:
   - Formulaire email + username + password
   - react-hook-form + Zod (RegisterDto du shared)

8. Cree front/src/features/auth/components/register.container.tsx:
   - Appelle auth.store.register
   - Passe les props a register.view

Execute: pnpm typecheck && cd front && pnpm test.
