Package 5: Audit & Monitoring.

Contexte: donjon-dragon SaaS. Auth + multi-tenant deja en place.

A FAIRE:

1. Cree back/src/audit/domain/audit-log.entity.ts:
   - type AuditLogEntry = { id, action, resource, resourceId, tenantId, userId, metadata, ip, userAgent, timestamp, type: 'audit' | 'security_event', severity: 'LOW' | 'MEDIUM' | 'HIGH' }
   - createAuditLog(action, resource, resourceId, tenantId, userId, metadata): AuditLogEntry

2. Cree back/src/audit/domain/audit.repository.port.ts:
   - interface IAuditRepository: log(entry), findByTenant(tenantId, filters?), findByUser(userId, filters?)

3. Cree back/src/audit/infrastructure/audit-mongo.repository.ts:
   - Implements IAuditRepository avec Mongoose
   - Index sur tenantId+timestamp, userId

4. Cree back/src/audit/interface/interceptors/audit-log.interceptor.ts:
   - Intercepte toutes les requetes POST/PUT/PATCH/DELETE
   - Log: action, resource, tenantId, userId, ip, body (sans password/token)

5. Cree back/src/audit/interface/filters/security-event.filter.ts:
   - Capture 401/403/429: login failed, access denied, rate limit
   - Log dans audit avec type: 'security_event' et severity appropriee

6. Cree back/src/audit/interface/audit.module.ts:
   - Importe MongooseModule + AuditService

Execute: pnpm typecheck && cd back && pnpm test.
