Package 2: App Security Middleware.

Deja installes dans back/: helmet, @nestjs/throttler, cookie-parser, @types/cookie-parser.
Auth deja en place avec JwtAuthGuard global, @Public(), @CurrentUser().

A FAIRE:

1. Modifie back/src/main.ts:
   - Ajoute import helmet from 'helmet';
   - Ajoute import cookieParser from 'cookie-parser';
   - Apres NestFactory.create:
     app.use(helmet());
     app.use(cookieParser());
   - Modifie app.enableCors():
     app.enableCors({ origin: process.env.FRONTEND_URL || 'http://localhost:5173', credentials: true });
   - Ajoute validation pipe global:
     import { ValidationPipe } from '@nestjs/common';
     app.useGlobalPipes(new ValidationPipe({ whitelist: true, forbidNonWhitelisted: true, transform: true }));
   - Ajoute body parser limit:
     import { json } from 'express';
     app.use(json({ limit: '1mb' }));

2. Cree back/src/config/index.ts:
   export const JWT_SECRET = process.env.JWT_SECRET || 'dev-secret-change-me';
   export const JWT_EXPIRES_IN = '15m';
   export const REFRESH_TOKEN_EXPIRES_IN = 7 * 24 * 60 * 60 * 1000; // 7 days
   export const FRONTEND_URL = process.env.FRONTEND_URL || 'http://localhost:5173';
   export const PORT = parseInt(process.env.PORT || '3000', 10);
   export const THROTTLE_TTL = 60000; // 60s
   export const THROTTLE_LIMIT = 10; // max 10 requests per TTL

3. Modifie back/src/app.module.ts:
   - Ajoute: import { ThrottlerModule } from '@nestjs/throttler';
   - Ajoute: import { ThrottlerGuard } from '@nestjs/throttler';
   - Ajoute: import { APP_GUARD } from '@nestjs/core'; (deja si present)
   - Dans imports: ThrottlerModule.forRoot([{ ttl: 60000, limit: 10 }])
   - Garde les APP_GUARD existants, ajoute { provide: APP_GUARD, useClass: ThrottlerGuard } en dernier

Execute: pnpm typecheck. Si erreurs, corrige. Puis: cd back && pnpm test.
