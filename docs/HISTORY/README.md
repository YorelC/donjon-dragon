# Archives des échanges

Ce répertoire conserve les transcriptions de sessions ayant contribué aux décisions du
produit. Ces fichiers sont des **archives non normatives**.

## Utilisation

- Ne pas demander à un agent de lire toutes les archives avant de développer.
- Consulter une archive uniquement pour retrouver l'origine d'une décision, comprendre
  une contradiction ou vérifier qu'aucune nuance n'a été perdue.
- Toute règle encore applicable doit être reformulée dans `PRODUCT.md`,
  `REQUIREMENTS.md`, un document technique ou `DECISIONS/`.
- Une spécification et une décision validées prévalent toujours sur un échange ancien.

## Convention

Un transcript est nommé `<date>-<sujet>.md`. Il est régénéré tant que la session reste
active, puis considéré comme figé après sa clôture. Une session ultérieure produit une
nouvelle archive plutôt que de modifier l'ancienne.

Une décision peut mentionner en provenance le fichier de session et le numéro du
message, mais elle doit rester entièrement compréhensible sans cette référence.
