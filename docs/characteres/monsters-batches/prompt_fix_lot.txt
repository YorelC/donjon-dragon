## Pièges à éviter

- **Type qui déborde** : le type ne contient QUE le type (ex: "Monstruosité (Lycanthrope)"). Pas la taille, pas l'alignement, pas le texte qui suit. Arrête-toi au premier "de taille" ou "Initiative" ou "," après le type.
- **Actions vides** : CHAQUE monstre qui a une section "Actions" dans le texte DOIT avoir ses actions extraites. Même les githyanki, empyréens, flagelleurs mentaux.
- **Séparateur de traits/actions** : les items sont séparés par " . " (espace-point-espace). Chaque item a un nom avant le " . " et une description après.
- **Sections sans items** : si une section n'existe pas dans le texte, le tableau est vide []. Ne mets pas le texte brut dans un champ scalaire.
