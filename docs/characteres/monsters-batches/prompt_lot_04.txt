## Règles d'extraction

- **abilities** : extraire des lignes `For <val> <mod> <save>` etc. Si absent, toutes les valeurs sont null.
- **skills** : concaténer tout après "Compétences" jusqu'au prochain libellé (Sens / Immunités / Langues).
- **damageImmunities** : extraire après "Immunités" (dégâts seulement, pas les états). Ex: "Immunités feu" → "feu".
- **conditionImmunities** : après "Immunités", tout ce qui est un état (Charmé, Empoisonné, Épuisement, etc.).
- **damageResistances** : après "Résistances" (dégâts).
- **damageVulnerabilities** : après "Vulnérabilités" (dégâts).
- **traits** : section "Traits" jusqu'à "Actions". Chaque trait commence par un nom suivi d'un point puis la description.
- **actions** : section "Actions" jusqu'à "Actions Légendaires" ou "Réactions" ou "Actions Bonus" ou la source.
- **bonusActions** : section "Actions Bonus".
- **reactions** : section "Réactions".
- **legendaryActions** : section "Actions Légendaires".
- **mythicActions** : section "Actions Mythiques".
- **source** : dernière ligne significative avant le nom EN/ES.
- **nameEN** : ligne contenant "[EN]"
- **nameES** : ligne contenant "[ES]"
- Si une section n'existe pas, le tableau correspondant est vide `[]`.
