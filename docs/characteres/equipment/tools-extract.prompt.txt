## Schéma JSON

```json

  {
    "key": "string (slug: nom en minuscules, accents conservés, espaces → tirets)",

    "cost": "string (ex: '50 po', 'variable')",
```

## Règles d'extraction
- **key** : lowercase du nom, accents conservés, espaces→tirets, apostrophes supprimées
- **category** : "outil d'artisan" si avant le heading "Autres outils", sinon "autre outil"
- **characteristic** : extraire après "Caractéristique : "
- **weight** : extraire après "Poids : ". "—" → null
- **use** : extraire après "Utilisation : "
- **craft** : extraire après "Artisanat : "
- Pour "Instrument de musique", les variantes sont dans le champ Artisanat
- Pour "Boîte de jeux", les variantes sont dans le champ Artisanat
