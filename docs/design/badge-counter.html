Badge compteur — onglet "Reçues"

Composant cible : Badge de shadcn/ui (variant="default") comme child du TabsTrigger.
Le badge est rendu uniquement quand receivedCount > 0 (UA-006, UA-010).
Affiche 9+ quand receivedCount > 9 (UA-007).

● Scénario A : 3 demandes (UA-006)

Badge "3" : affiché car receivedCount=3 > 0

● Scénario B : 12 demandes (UA-007 — truncation 9+)

Badge "9+" : affiché car receivedCount=12 > 9

● Scénario C : 0 demande (UA-010 — badge masqué)

Badge caché : receivedCount=0, pas de rendu conditionnel

● Scénario D : 1 demande (UA-006 — minimum)
