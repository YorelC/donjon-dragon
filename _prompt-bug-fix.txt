bug fix : page /profile/friends affiche 'Chargement...' en permanence.

cause identifiee : TanStack Query retry 3 fois par defaut. Si l'API renvoie 401 (pas de JWT valide), la query reste en isLoading pendant les retries, ce qui bloque l'affichage.

fix :
1. Dans use-friends.ts, use-received-requests.ts, use-sent-requests.ts : ajouter `retry: false` dans l'option de useQuery
2. Optionnel : dans friends.container.tsx, gerer le cas isError pour les queries individuelles (afficher un message d'erreur specifique)
3. Verifier que typecheck et tests passent

les fichiers sont dans front/src/pages/profile/friends/_internal/queries/
